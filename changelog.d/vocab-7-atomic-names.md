kind: **BREAKING**: vulkan vocabulary version 7 (`a64` `af32` `af64`, kiss-vulkan-vocab 0.6.0), repin to unpopped ~0.56.2 / fishstringer ~0.4.0, by-name patent declines
---
Three changes in one PR (one PR per day, PM 2026-11-16).

**1. Vocabulary 7.** Adds the atomic capability names `a64`, `af32` and `af64` to the `vulkan:` `<arith>` field (KISS#837, KISS 0.19.0): `vulkane::safe::PhysicalDevice::shader_atomic_features` / `ShaderAtomicFeatures` read `VkPhysicalDeviceShaderAtomicInt64Features` and `VK_EXT_shader_atomic_float` (chained only when the device lists the extension; a failed extension enumeration declines), and `vulkane::kiss::DeviceCapabilities` derives the names from them. Breaking for tokens: a device with 64-bit atomics now spells `a64`. `kiss-vulkan-vocab` moves to 0.6.0 on its own version line (CHANGELOG section above, with the migration); the manifest changes in three lines. ROADMAP row 8d-cap.

**2. Repin.** `unpopped`, `unpopped-vocab`, `unpopped-cpu-c`, `unpopped-convert` `~0.47.0` -> `~0.56.2` and `fishstringer-*` `~0.2.0` -> `~0.4.0` (0.4.0 requires `unpopped ^0.56.1`; the `Backend` trait must be the same one on both sides), across the emit/parse crates and `vulkane`'s dev-dependency on `fishstringer-kernels-source`. Source compiled unchanged.

**3. Patent declines by name, eleven statements (board 434 C and its extension; NVIDIA US11294713B2, US12118382B2, US11803380B2, US12204897B2).** `vulkane-spirv-emit`, `vulkane-hlsl-emit` and `vulkane-wgsl-emit` override `Backend::lower_kernel` and refuse `CopyAsync`, `AsyncCommit`, `AsyncWait`, `Collective` (board 434 C) and `MbarInit`, `MbarArrive`, `MbarCompleteTx`, `MbarWait`, `CopyBulk`, `Tcgen05Commit`, `WgmmaWait` (extension) by name with `LowerError::UnsupportedKernel`, at the top level and at any `If`/`For`/`While` depth, via an exhaustive `Stmt` match (no wildcard: a new statement fails to compile until classified). Every other kernel gets the same typed refusal as before. `tests/patent_decline.rs` in each crate pins all eleven names at six nesting shapes with a control; a mutation that drops one name fails it; `CollectiveTuple` is deliberately not named. ROADMAP row 8l; the READMEs carry the builder warning.
